# Roblox Creator Documentation

> Documentation for building experiences, avatars, and cloud integrations on the Roblox platform using Roblox Studio and the Luau programming language.

## For Code Agents: Start Here

| Call Roblox REST APIs from an **external server or tool** | [Open Cloud API index](/docs/cloud/llms.txt) |
| Check whether an API was removed or replaced | [Deprecated API inventory](/docs/reference/engine/deprecated.md) |

**Never guess a URL.** The sections at the end of this file list 2297 documentation pages, each with its full path. A path that appears in no index does not exist. A guess that looks plausible returns a 404 whose body is a page of HTML markup that tells you nothing, so each one spends a request and a slice of your context to learn nothing. Never extrapolate a path from a pattern you noticed in another one.

**Search for the page you need.** Put a plain-language question straight into the path: `/docs/api/search/how%20do%20I%20publish%20an%20avatar%20look`. The answer is JSON listing the pages that match, each with a title, a summary, and a `url` that already points at the Markdown and can be fetched exactly as given. Percent-encode the spaces as shown, or split the question into path segments (`/docs/api/search/how/do/I/publish`) -- both work, but a raw space is not a legal URL and some tools refuse to send it. **Write a space instead of a period.** A period anywhere in the path makes the request look like a file, and it is answered with a 404 before the search ever runs. For example, ask about `Vector3 new` rather than `Vector3.new`, and don't include the period that ends a sentence. This is the same index behind the search box on the site, and it matches on meaning rather than on words, so a whole question works better than a keyword. It is the shortest path from a question to the right page.

**An `error` field in a search response means your request was malformed, not that nothing matched.** A bad call and a search with no matches both answer 200 with an empty `results` array, so check for `error` before concluding a topic is undocumented. The `usage` field beside it shows the form that works.

**A 404 means your path is wrong, not that the topic is undocumented.** Search for the page rather than trying another variation of the path that just failed.

**Add `.md` to any documentation URL to read it as Markdown.** Every page is served twice: as HTML at its normal URL, and as plain Markdown at that same URL with `.md` on the end. The Markdown is a fraction of the size and carries no navigation or page furniture. Every link below already ends in `.md`, so keep the extension when you follow one.

**This file is a couple hundred kilobytes, which is more than some fetch tools return in one call.** If you cannot see the `##` section listings further down, you have only the beginning of it. Search, or fetch a sub-index below, rather than guessing at what the rest of the file contained.

Do not fetch [/docs/llms-full.txt](/docs/llms-full.txt) unless you can stream it. It inlines the full text of all 2297 pages into a single file of tens of megabytes, which will exhaust or truncate your context long before it answers anything. Read the individual `.md` pages you need instead.

> **Common mistake**: The Engine API and Open Cloud API are completely separate systems.
> Engine APIs are Luau objects accessed via `game:GetService()` inside a running experience.
> Open Cloud APIs are HTTP endpoints called with `x-api-key` from outside Roblox entirely.
> Using the wrong sub-index will produce non-functional code.

---

Roblox is a platform where millions of people create and share 3D experiences. Creators use Roblox Studio (the IDE) and Luau (the scripting language) to build games, experiences, and avatar items. The platform provides Engine APIs for in-experience scripting and Open Cloud APIs for server-side integrations.
