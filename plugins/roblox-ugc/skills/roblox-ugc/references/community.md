# Community technique review

Community material complements official authoring guides. It does not establish current Marketplace limits, fees, admission rules or acceptance. Review records and unavailable sources are in `corpus/external-review.json`.

| Tutorial | Useful technique / adoption decision |
| --- | --- |
| [Cartoony top hat](https://devforum.roblox.com/t/ugc-hat-tutorial-cartoony-top-hat/1078816) | Simple cylinder-based modeling gives a manageable rigid silhouette. Keep the mesh/UV technique; old UGC application context and Blender keybindings are historical. |
| [Hair in Blender, part 2](https://devforum.roblox.com/t/how-to-make-ugc-hair-in-blender-28-pt-2/612848) | Reduce curve resolution deliberately before mesh conversion and inspect the final triangulated count. Hair texture authoring is useful; do not install an extra old tool merely because the author used it. |
| [Visual 3D pipeline](https://devforum.roblox.com/t/3d-art-a-visual-representation-of-the-3d-pipeline/2659618) | Distinguish sculpting, retopology, UV and texture/baking stages. Its claim that PBR is limited to clothing is obsolete for current rigid workflows. Software pricing/admission advice is historical; use current texture/category specs. |
| [UGC bundles](https://devforum.roblox.com/t/how-to-properly-configure-and-import-ugc-bundles/3094203) | Normal-transfer can preserve shading when separating limbs; preserve the official cage's correspondence. Do not blindly copy neck joints or zero cage origins using this model-specific advice. Current import settings, attachment transforms and actual validation determine the repair. |
| [Layered clothing through Avatar Setup](https://devforum.roblox.com/t/guide-layered-clothing-in-roblox-without-cages-or-rig-blender-avatar-setup/3793130) | “Without cages/rig” describes skipping manual preparation. Studio-generated output still requires correct components, fit and validation; it is not permission to submit invalid cage data. |
| [Marvelous Designer/CLO cages](https://devforum.roblox.com/t/marvelous-designer-layered-clothing-cages/4140561) | Clothing simulation is followed by retopology, UV/baking and cage fitting. The shared cages target a particular base avatar; inspect topology, provenance and target fit before adopting them. |
| [Outer-cage discussion](https://devforum.roblox.com/t/modeling-an-outer-cage-for-avatar-accessories/2734001) | Its UV-copy technique is safe only when vertex/loop correspondence is preserved. Visible vertices or a local validator passing do not prove cage fit or Marketplace acceptance. Avoid adopting clipping/deletion workarounds or downloading others' cages as a generic repair. |
| [Dubit dynamic-head video](https://vimeo.com/1030106632) | Video candidate; metadata was retrieved. Visual instructions remain unreviewed. |
| [Jezixa head guide](https://www.youtube.com/watch?v=apZsJqsKdw4) | Full captions analyzed; useful modeling/weighting techniques and template-specific pitfalls are recorded in `corpus/community-videos.json`. Its pose-count/price and universal export-scale claims are not official requirements. Visual steps and reproduced output remain unchecked. |
| [NoCapMocap emote publishing](https://www.nocapmocap.com/blog/how-to-publish-a-roblox-emote) | Distinguish a development animation from the Marketplace Avatar Item. The editor-generated Emote object can carry a publishing marker omitted by manual wrapping. Verify current Studio behavior; ignore unverified commercial “ready” claims and refresh fees/eligibility from Roblox. |

When following a community workflow, preserve an editable project, compare the source's tool version and category to the present task, then run the applicable offline/Studio checks. Label a technique as reproduced only after inspecting its resulting artifact. Community source review here is not end-to-end validation of every author's workflow.
